## Verified acceptance cases

Specification basis. Read standard JSDoc attached to exported functions in one JavaScript text-file reading.

| Case | Check | Behavior |
| --- | --- | --- |
| ` JSDOC-REEXPORT ` | source invariant | A documented re-export uses its public alias and retains the upstream callable signature. |
| ` JSDOC-INVALID-SOURCE ` | source refusal | Invalid text-file carriers and malformed JavaScript refuse before emitting documentation. |
| ` JSDOC-QUICKSTART ` | consumer example | An installed caller can read the public name, description, parameter and return type of a documented function. |

Runtime requirement. ` >=24 `
