#### ` readJavascriptFileExportDocumentation `

```javascript
export function readJavascriptFileExportDocumentation(reading)
```

Reads standard JSDoc for locally declared exported functions and named foreign re-exports. Local aliases use their declaration's signature; foreign bindings retain their export syntax and origin without a claim about their runtime kind. The source is parsed, never executed.

Parameters:

| Name | Type | Optional | Description |
| --- | --- | --- | --- |
| reading | object | no | A TextFileRead carrying the JavaScript path and source text. |

Returns ` readonly object[] `: Version 1 JavascriptFileExportDocumentation records with function or reexport kinds, in export order.

Throws:

- ` TypeError `: When the input is not a TextFileRead carrier.
- ` SyntaxError `: When the carried JavaScript does not parse.
